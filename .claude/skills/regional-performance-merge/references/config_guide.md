# 설정 파일(JSON) 작성 안내

`merge_regions.py`는 설정 파일 하나로 여러 원본 파일을 읽는다. 경로(`input_dir`, `output`)는 **설정 파일이 있는 폴더 기준**이며 절대경로도 쓸 수 있다. 완성된 예시는 `config_example.json`이다.

## 공통 항목

| 항목 | 필수 | 설명 |
|---|---|---|
| `title` | | 통합실적 시트 제목 |
| `note` | | 시트 2행 안내문 (자료 출처, 금액 기준 등) |
| `period` | ✓ | 보고기간 `YYYY-MM`. 이 달이 아닌 날짜는 "보고기간 밖"으로 제외 |
| `input_dir` | | 원본 파일 폴더 (기본: 설정 파일 폴더) |
| `output` | ✓ | 결과 xlsx 경로. 원본과 다른 새 파일 이름을 쓴다 |
| `campaign_map` | ✓ | 캠페인 코드 → 활동구분 이름 |
| `product_map` | ✓ | 원본 상품 표기 → 표준 상품명 |
| `status_map` | ✓ | 원본 상태 표기 → `마감` 또는 `미마감` |

매핑에 없는 값이 나오면 스크립트가 멈추고 그 값을 알려준다. 추측해서 넣지 말고 사용자에게 어떤 값으로 바꿀지 확인한 뒤 매핑에 추가한다.

## `sources` 항목 (파일 하나당 하나)

| 항목 | 필수 | 설명 |
|---|---|---|
| `region` | ✓ | 지역(또는 부서) 이름 |
| `file` | ✓ | 파일 이름 (.xlsx 또는 .csv). 한글 정규화(NFC) 차이는 자동 처리 |
| `header_row` | ✓ | 머리글이 있는 행 번호 (1부터). 모든 대상 시트에 같게 적용 |
| `columns` | ✓ | 표준 항목 → 원본 머리글 이름. 공백·줄바꿈은 무시하고 비교 |
| `sheets` | | 읽을 시트 이름 목록 (없으면 모든 시트) |
| `skip_sheets` | | 뺄 시트 (전월 참고요약 등) |
| `date_format` | | 날짜가 글자일 때 형식. 예: `%Y/%m/%d`, `%Y.%m.%d`, `%Y%m%d`. 실제 날짜 셀이면 생략 |
| `amount_multiply` | | 원 단위로 바꾸는 곱셈 (천원 1000, 만원 10000) |
| `amount_divide` | | 나눗셈 (VAT 포함 금액이면 1.1) |
| `unit_note` | | 변환기준 시트에 적을 설명 |
| `campaign_from` | | 캠페인 열이 없을 때 코드 찾는 방법. `source`: `sheet_note`(머리글 위 안내문) 또는 `sheet_name`, `pattern`: 정규식 (첫 번째 괄호가 코드) |

### `columns`의 표준 항목

`id`(기록ID), `rev`(수정차수, 없으면 1), `date`, `campaign`(또는 `campaign_from`), `product`, `amount`, `lead`(상담), `appl`(신청·접수), `cancel`, `done`(완료), `status`(마감 상태)

## 자주 생기는 문제

- **"머리글에 'OO' 열이 없음"**: `header_row`가 틀렸거나 열 이름 철자가 다르다. 오류 메시지에 실제 머리글이 함께 나온다.
- **"일반 xlsx가 아님"**: 사내 문서보안(DRM) 파일일 가능성이 높다. 보안 해제본을 받아야 한다.
- **"통합 후에도 같은 기록ID가 남음"**: 같은 ID·같은 차수인데 내용이 다른 행이 있다. 어느 값이 맞는지 사용자에게 확인한다.
- **반올림 경고**: VAT ÷1.1 결과가 원 단위로 안 떨어지는 경우다. 검증 시트 아래에 목록이 남는다.
- **금액·숫자에 글자가 섞임** (`"120,600"`, `1,200원`, `₩300`, `30건`): 자동으로 숫자로 바꾼다. 빈칸은 0이 아니라 빈 값으로 남긴다.
