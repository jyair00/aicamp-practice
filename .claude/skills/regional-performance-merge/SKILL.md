# 지역별 실적 파일 통합

여러 지역(또는 부서)에서 따로 만든 실적 파일을 **1행 = 1건**인 표준 표 하나로 합친다. 파일마다 단위·열 이름·상태 표기가 달라서 그대로 붙이면 합계가 틀린다. 이 스킬의 핵심은 "합치기"보다 **차이를 먼저 찾아 사용자에게 보여주고, 합친 뒤 원본과 숫자가 맞는지 증명하는 것**이다.

## 작업 순서

### 1. 원본 구조 확인 (아무것도 고치기 전에)

`scripts/inspect_files.py`로 폴더 안 파일을 모두 훑는다. 시트 이름, 병합 셀, 위쪽 안내문, 머리글 후보, 첫·마지막 행을 UTF-8 텍스트 파일로 저장해 읽는다. 한글이 콘솔에서 깨질 수 있으므로 결과는 파일로 받는다.

```bash
python scripts/inspect_files.py <입력폴더> <결과.txt>
```

- 파일 앞부분이 `PK`(정상 xlsx)가 아니면 사내 문서보안(DRM)으로 암호화된 파일일 수 있다. 억지로 열지 말고 "보안을 해제한 파일이 필요하다"고 알린다.
- 시트 위쪽 안내문을 꼭 읽는다. 단위("천원", "VAT 포함 → 1.1로 나눔"), 캠페인 코드, "이 표는 더하지 마세요" 같은 지시가 거기에 있다.

### 2. 파일별 차이표를 사용자에게 보여주기

통합 전에 아래 항목을 파일별 표로 정리해 보여주고, 기준 형식에 대해 동의를 받는다. 사용자가 기존 기준 양식(예: 다른 지역의 취합본)을 알려주면 그 열 구성을 따른다.

| 확인 항목 | 흔한 차이 |
|---|---|
| 시트 구성 | 기간별 시트, 캠페인별 시트, 참고용 요약 시트 |
| 머리글 위치 | 1행, 4~6행, 묶음 제목 아래 |
| 금액 단위 | 원 / 천원 / 만원, VAT 포함·제외, `"120,600"` 같은 글자 |
| 날짜 형식 | `2026/08/01`, `2026.08.01`, `20260801`, 실제 날짜 |
| 코드 위치 | 캠페인 코드가 열이 아니라 시트 이름·안내문에만 있는 경우 |
| 값 표기 | `BB`/`BBTV` ↔ `인터넷`/`인터넷+B tv`, `Y/N`·`확정/잠정`·`마감/미마감` |
| 정리 대상 | 완전 중복 행, 같은 ID의 이전 차수, 보고기간 밖 날짜, 미마감 행 |

원본 그대로의 단순 합계도 함께 보여주되, 단위가 달라 서로 비교하면 안 된다고 적는다.

### 3. 설정 파일 작성 → 통합 실행

파일별 읽는 방법을 JSON 설정으로 적고 `scripts/merge_regions.py`를 실행한다. 설정 예시는 `references/config_example.json`(영남·충청·호남·강원제주 4개 형식)에 있고, 각 항목 설명은 `references/config_guide.md`에 있다. 새 파일 형식이면 이 두 파일을 먼저 읽는다.

```bash
python scripts/merge_regions.py <설정.json>
```

스크립트가 지키는 규칙과 그 이유:

- **금액은 원·VAT 제외·숫자로 통일한다.** 천원 ×1,000, 만원 ×10,000, VAT 포함 ÷1.1. 환산 결과가 원 단위로 딱 떨어지지 않으면 반올림하고 검증 시트에 적는다. 단위가 섞이면 합계가 수십 배 틀린다.
- **제외 판정 순서: 보고기간 밖 → 완전 중복 → 이전 차수.** 같은 ID가 여러 차수로 있으면 가장 높은 차수만 남긴다. 순서를 지켜야 제외 사유가 한 행에 하나로 정확히 붙는다.
- **미마감 행은 지우지 않는다.** 통합표에는 남기고 `마감여부=미마감`으로 표시해 확정 합계에서만 뺀다. 나중에 마감되면 상태만 바꾸면 된다.
- **빈 금액에 0을 넣지 않는다.** 비워 두고 메모에 "금액 비어 있음 — 확인 필요"를 남긴다. 0원과 미입력은 의미가 다르다.
- **참고용 시트(전월 요약 등)는 설정의 `skip_sheets`로 뺀다.**
- **원본 파일은 수정하지 않는다.** 결과는 새 파일로만 저장한다.

### 4. 결과 파일 구성

| 시트 | 내용 |
|---|---|
| 통합실적 | 표준 열 15개, 미마감 행은 연한 주황 + 메모, 원본 파일·시트·행 위치 |
| 지역별요약 | 원본·제외·통합·미마감·확정 행 수, 확정/미마감 금액, 확정 건수 (엑셀 수식) |
| 제외내역 | 뺀 행과 이유 |
| 검증 | 지역별로 `원본 = 통합 + 제외`가 행 수·금액·건수에서 맞는지, 차이와 일치 여부 |
| 변환기준 | 지역별 단위 환산, 상품명·상태값 매핑 |

표준 열: `지역 | 집행일 | 활동구분 | 캠페인ID | 기록ID | 수정차수 | 대상상품 | 사용금액(원/VAT별도) | 상담 건수 | 접수건 | 취소 | 처리완료 | 마감여부 | 메모 | 원본파일·시트`

### 5. 검증하고 보고하기

스크립트가 표준 출력으로 지역별 요약 JSON을 낸다. 검증 시트에서 하나라도 "불일치"가 있으면 완료라고 말하지 말고 원인을 찾는다.

사용자에게는 결론부터, 다음을 함께 보고한다.
- 결과 파일 경로
- 지역별 원본 행 / 제외 / 통합 / 확정 행, 확정 금액·미마감 금액과 **합계** (원본 건수와 합계를 같이 적는다)
- 제외 사유별 건수
- 확인하지 못한 것 (DRM 파일, 빈 금액, 원 단위로 안 떨어진 환산 등)

## 디자인

결과 엑셀은 흰 바탕에 머리글만 SK Red(`#EA002C`), 미마감 강조는 연한 주황, 글꼴은 맑은 고딕을 쓴다. 회사 템플릿이 따로 있으면 그 형식을 먼저 따른다. 색만으로 상태를 구별하지 않도록 `마감여부` 열에 글자로도 적는다.

## 필요한 것

Python 3.9 이상과 `openpyxl`. 설치되어 있지 않으면 `pip install openpyxl`.
