# 회사 요약재무 빠른 조회

웹 검색·브라우저를 거치지 말고 **스크립트 한 번**으로 끝낸다. 보통 2초 안에 끝난다.

## 실행

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".claude\skills\company-financials\get_financials.ps1" -Name "에스케이브로드밴드"
```

- `-Name`: 사용자가 말한 회사명을 그대로 넣는다. 스크립트가 SK↔에스케이, LG↔엘지, KT↔케이티 등 두 표기를 자동으로 시도한다(DART 공시명이 `SK텔레콤`, `에스케이브로드밴드`처럼 회사마다 다름).
- `-Crno 1101111466659`: 법인등록번호를 알면 회사 검색을 건너뛴다.
- `-FromYear` / `-ToYear`: 기본은 최근 5년~올해. API에 없는 연도는 그냥 0건이다.
- `-OutCsv 경로`: 엑셀용 CSV로 저장한다. 엑셀 정리를 요청받으면 이 CSV를 입력으로 쓴다.

자주 쓰는 법인등록번호: 에스케이브로드밴드 `1101111466659`

## 결과 처리

- 출력은 억원 단위(원 단위 반올림), 부채비율은 %다. 연결·별도를 구분해 표로 보여준다.
- 답변에는 **출처(공공데이터포털 금융위원회_기업 재무정보), 단위, 건수, 조회 연도 범위**를 함께 적는다.
- 증감은 출력 숫자로만 계산한다. 출력에 없는 연도·분기 수치는 만들지 않는다. 분기 실적이 필요하면 API에 없다고 알리고 DART 분기보고서를 안내한다.

## 오류별 대처 (스크립트 종료 코드)

| 코드 | 상황 | 다음 행동 |
|---|---|---|
| 2 | API 키 없음 | `.env`에 `DATA_GO_KR_API_KEY` 를 넣도록 안내 |
| 3 | DART에서 회사 못 찾음 | 공시 회사명(한글 표기)으로 한 번 다시 실행 |
| 4 | 후보 여러 개 | 출력된 후보 중 맞는 이름으로 다시 실행하거나 사용자에게 고르게 함 |
| 6 | 재무자료 0건 | 연도 범위를 넓혀 한 번 더, 그래도 없으면 비상장 소규모 등으로 API에 없다고 안내 |

## 이미 확인된 함정 (다시 조사하지 말 것)

- 연산 이름 끝에 `_V2`가 필요하다: `GetFinaStatInfoService_V2/getSummFinaStat_V2`. 빠지면 빈 본문의 HTTP 400이 난다.
- 회사망에서는 Python `requests`가 SSL 인증서 오류(self-signed)를 낸다. Windows 인증서를 쓰는 PowerShell 스크립트를 사용한다. 인증서 검증을 끄지 않는다.
- 기업기본정보 API(`GetCorpBasicInfoService_V2`)는 이 키로 403이라 쓰지 않는다. 회사명→법인등록번호는 DART 공개 검색으로 찾는다.
- API 키 값을 화면·답변에 출력하지 않는다.
