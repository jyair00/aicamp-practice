# 루멘포레 고객안내 콘텐츠 용역계약안 — 발주자(갑) 검토 의견

- 검토 대상: `루멘포레_고객안내콘텐츠_용역계약서.pdf` (5쪽, 제1조~제14조 + 납품 명세)
- 계약안 번호: FICTION-CONTENT-2026-09-01 / 공급사 제안본 v1.0 / 작성 기준일 2026. 9. 7. / 미서명
- 검토 관점: 발주자인 **갑(SK브로드밴드 가상 발주부서)** 입장
- 주의: 교육용 가상 자료입니다. 이 의견은 실습용 검토 메모이며 법률 자문이 아닙니다. 실제 계약이라면 법무·정보보호 부서의 확인이 필요합니다.

---

## 1. 결론

**이대로 체결하면 안 됩니다.** 공급사가 만든 제안본이라 대부분의 위험이 갑에게 몰려 있어요.

가장 큰 문제 다섯 가지입니다.

1. **이용 범위가 너무 좁아요 (제7조).** 1년 동안, 갑이 직접 운영하는 온라인 채널에서만 쓸 수 있어요. 유료 광고, 영업점 화면, 자막 교체도 별도 동의와 비용이 필요해요.
2. **검수 전에 대금을 100% 지급해요 (제4조②).** 선급 60%에 잔금 40%까지 납품 전에 지급하고, 검수 기간은 3일뿐이에요.
3. **검수가 끝나면 하자 책임이 없어요 (제5조③, 제10조②).** 재생 오류나 문구 오기가 나중에 발견돼도 수정이나 감액을 요구할 수 없어요.
4. **해지 조건이 한쪽에만 불리해요 (제11조).** 갑이 해지하면 진행 정도와 관계없이 100% 위약금을 내요. 을이 중단하면 돈을 돌려줄지조차 "협의"예요.
5. **재위탁과 자료 전달이 자유로워요 (제9조).** 을이 갑에게 알리지 않고 협력업체에 일을 맡기고 갑의 자료를 넘길 수 있어요. 고객자료도 같은 절차를 따르게 되어 있어요.

## 3. 조항별 쟁점과 수정 의견

중요도: **상** = 체결 전 반드시 수정 / **중** = 수정 권장 / **하** = 문구 명확화

| 중요도 | 조항 | 현재 내용 | 문제점 | 수정 의견 |
|---|---|---|---|---|
| 상 | 제7조① | 저작재산권은 을 소유. 갑은 완납일부터 1년, 직접 운영 온라인 채널에서만 비독점 사용 | 고객안내 캠페인인데 1년 뒤에는 쓸 수 없어요. 완납이 납품 전이라 실제 사용 기간은 1년보다 짧아요 | 저작재산권을 갑에게 양도하거나, 기간·매체 제한 없는 이용허락으로 바꿉니다 |
| 상 | 제7조② | 영업점 화면, 사내 교육, 유료 광고, 지역별 재편집, 자막 교체, 다른 제작사 편집은 을의 동의와 별도 비용 필요 | 요금·안내 문구가 바뀌어도 갑이 자막을 고칠 수 없어요. 편집 파일을 받아도 쓸 수 없어요 | 위 용도를 기본 이용 범위에 넣습니다. 편집 파일로 갑이나 제3자가 수정할 수 있다고 명시합니다 |
| 상 | 제4조② | 잔금 40%를 최종 납품 예정일 3영업일 전까지 지급. 잔금을 받은 뒤 납품 | 결과물을 보기 전에 100%를 지급해요 | 예: 선급 30% / 1차 시안 승인 후 30% / **검수 완료 후** 40% |
| 상 | 제5조② | 납품일 포함 3일(휴일 포함) 안에 통지가 없으면 검수 완료로 간주 | 영상 4편과 이미지 6종을 3일 안에 확인하기 어려워요 | 영업일 기준 7~10일로 늘립니다. "검수 간주" 조항은 빼거나 기간을 늘린 뒤 적용합니다 |
| 상 | 제5조③ | 검수 후 재생 오류·문구 오기·사양 불일치가 발견돼도 하자보수·감액 불가 | 고객에게 틀린 안내가 나가도 고칠 방법이 없어요 | 검수 후 일정 기간(예: 6개월) 하자보수 의무를 넣습니다. 을의 잘못으로 생긴 오류는 무상으로 고칩니다 |
| 상 | 제11조① | 갑의 사정으로 해지하면 진행 정도와 관계없이 100% 위약금 | 착수 다음 날 해지해도 전액을 내요 | 진행 단계별로 실제 작업분만 정산합니다. 위약금 상한도 정합니다 |
| 상 | 제11조② | 을이 중단하면 기지급금 반환 여부·시기는 "협의". 갑은 추가 배상 청구 불가 | 선급금 14,520,000원을 돌려받지 못할 수 있어요 | 미완료분 기지급금 반환 기한을 정합니다. 갑의 손해배상 청구권을 남깁니다 |
| 상 | 제9조①② | 재위탁 시 통지·동의 불필요. 을이 판단해 갑의 자료를 협력업체에 전달. 실제 고객자료도 같은 절차 | 갑의 자료가 누구에게 가는지 알 수 없어요. 제8조①(고객자료는 기본 제공 안 함)과도 어긋나요 | 재위탁은 **갑의 사전 서면 동의** 후 가능하게 합니다. 고객정보 제공은 이 계약에서 빼고, 필요하면 별도 개인정보 처리 계약을 맺습니다 (법무·정보보호 부서 확인) |

| 중 | 제4조③ | 갑이 늦게 지급하면 연 15% 지연이자 | 갑에게만 무거운 부담이 있고 을의 지연은 정하지 않았어요 | 이율을 낮추거나, 제10조 지체상금과 균형을 맞춥니다 |

| 하 | 제8조③ | 상대방이 요청해야 자료를 반환·삭제 | 요청을 잊으면 자료가 남아요 | 계약 종료 시 요청이 없어도 반환·삭제하고, 확인서를 제출하게 합니다 |

## 4. 괜찮은 조항 (유지)

- 제1조②: 실제 가입 조건·요금·혜택 변경은 범위에서 제외 — 업무 범위가 분명해요.
- 제2조③, 제6조③: 추가 촬영과 변경 업무는 견적 제출 후 갑의 서면 승인 — 추가 비용 통제에 좋아요.
- 제7조④: 을이 실적 소개에 쓰려면 갑의 사전 서면 동의 필요.
- 제8조①②: 고객 개인정보는 기본 자료에서 제외, 상호 비밀유지.
- 제14조③: 서명 전에는 발주 승인이나 지급 지시로 쓰지 않음.

## 5. 체결 전에 확인할 내용

1. 캠페인을 어느 매체에 얼마나 오래 쓸 계획인지 (유료 광고, 영업점 화면, B tv 화면 포함 여부)
2. 요금이나 안내 문구가 바뀔 때 사내에서 직접 자막을 고칠 계획이 있는지
3. 2026년 추석 연휴 날짜와 9월 말 사내 검토 일정
4. 을이 쓸 협력업체 명단과 보안 관리 방법
5. 출연자 초상권, 음원·폰트 라이선스의 사용 기간과 매체
6. 선급금 지급 시 이행보증(보증보험 등)을 받을 수 있는지
7. 서명 권한자와 사내 체결 절차 (제14조③)

## 6. 을에게 보낼 수정 요청 요약

> 1. 저작재산권 양도 또는 기간·매체 제한 없는 이용허락 (제7조)
> 2. 대금 지급을 단계별로 나누고 잔금은 검수 완료 후 지급 (제4조)
> 3. 검수 기간을 영업일 기준으로 늘리고, 검수 후 하자보수 기간 설정 (제5조)
> 4. 해지 시 실제 작업분만 정산하고, 을의 중단 시 기지급금 반환 기한 명시 (제11조)
> 5. 재위탁은 갑의 사전 서면 동의 후 가능, 고객자료 제공 조항 삭제 (제9조)
> 6. 을의 과실 책임과 지체상금 신설, 제3자 소재 분쟁 시 을의 책임 명시 (제10조)
> 7. 을의 실수 수정은 무상, 추가 비용은 공급가액 기준 견적 (제6조)
> 8. 관할 법원을 갑의 본점 소재지 관할로 변경 (제13조)
